# FICTÍCIO — Operação Isca (investigador-cyber-90-dias). Nenhuma pessoa, conta, número ou domínio real.

`pivos-isca.csv`: resultados pré-coletados (como o L1-L9 do *case packet*) sobre a infraestrutura da Operação Isca,
para a Prática BR do Dia 84. Cada linha é um valor compartilhado entre duas entidades. A coluna `explicacao_inocente`
traz o contexto que você precisa para decidir se o pivô é achado, pista ou rejeitado. Não há veredito no arquivo:
o veredito é seu.
